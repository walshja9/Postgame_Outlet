- Winner records, margin error, combined-score error, probabilities and pool accounting remain separate. Publish explicit denominators, unavailable cases and small-sample limits.

- Reuse native disclosures and current theme. No new UI framework, notification service or statistical dependency.
- Alerts must target only the user's account, avoid repeated messages for unchanged conditions, retain truthful board publication during source failures, and never include credentials or raw provider errors in a public issue. GitHub notifications are the default pending the user's delivery preference. Actual mailbox/email receipt is distinct from successful issue delivery.
- ATS size categories are fixed before this implementation's evaluation: zero disagreement is no edge; positive absolute disagreement under 1 point, 1 to under 3 points, and 3 or more points. This is descriptive monitoring, not a validated minimum selection threshold. Existing outcomes remain descriptive. Never label future observations prospective without a verified prior public protocol witness.
